SkillByte Design System v1

Vibrant, structural, fast.

This page is the reference for every decision the site is built from. Toggle the theme in the header — everything below re-maps through the same semantic tokens, so light and dark are one system rather than two designs.

01 — Colour

Three hues, each with exactly one job

Tide (teal) is the brand and its actions — navigation, buttons, links, the logo. Volt (green) is growth and confirmation, and Tide's partner in every gradient. Flare (orange) is reserved for outcomes: stat values, case-study metrics, attention. It never appears in navigation.

That last rule is what keeps the palette from turning into decoration. On this site, orange means a number. The neutrals are cool-tinted to sit under teal — a warm grey next to this teal reads muddy.

02 — Navigation

A floating pill that stays dark in both themes

The bar is a fixed dark object whichever theme you are in — that contrast against a light page is what gives it presence. In dark mode it lifts to a lighter navy rather than dissolving into the background. It overlays the page rather than sitting in a band above it, so the hero runs underneath.

Active state

A gradient pill plus a dot below it. The dot is what makes it read as “you are here” rather than just “this one is highlighted”.

Search

The magnifying glass is a working control, not decoration. It filters a small static index of pages and sections. Ctrl/Cmd + K opens it from anywhere.

No dropdown carets

The nav is five flat pages. A caret promising a menu that does not exist is a small lie, so there are none.

03 — Contrast rules

How a vibrant palette stays readable

Core teal on white measures 2.6:1 — fine for a button fill or an oversized headline, nowhere near enough for body copy. So every ramp splits by job: the 500s are for fills and display type, the 700s are for text, and dark mode mirrors that with the 300s. Every figure below is measured with axe-core, not estimated.

04 — Gradients

Used once or twice a page, never everywhere

A gradient that appears on every element stops meaning anything.

--grad-primary · buttons, nav active pill, logo mark

--grad-spectrum · hero type, scroll progress bar, button hover

--grad-highlight · stat values and case-study metrics ONLY

--grad-ink · nav pill, CTA bands, feature tiles

05 — Typography

Bricolage Grotesque + Inter

Both self-hosted variable fonts — every weight from one 77KB and one 48KB file, with no request to Google. Bricolage has real character in its display sizes without tipping into novelty; Inter stays invisible in body copy, which is the job.

--step-0 · body · Inter 400

Body copy sits at a fluid 16–18px with a 1.6 line height and a 60-character measure. Every step in the scale interpolates between a mobile floor and a desktop ceiling, so type never jumps at a breakpoint — it grows smoothly with the viewport.

09 — Forms

Feedback that feels responsive

Fields glow on focus with a 4px brand halo. Errors validate on blur, then correct live as you type — so nobody is told they're wrong while still typing.

10 — Motion

Fast, purposeful, and fully optional

One easing curve does almost all the work. Everything is gated behind prefers-reduced-motion: movement is removed, opacity fades stay, and no content is ever hidden by a script that failed to run.

Durations

90ms press feedback · 180ms hover · 280ms UI transitions · 520ms scroll reveals

Easing

cubic-bezier(.22,1,.36,1) for nearly everything. A spring curve is reserved for icons and toggles.

Scroll

Native CSS animation-timeline where supported, IntersectionObserver everywhere else. No animation library.
